# T05: Signed battery/grid series + battery SOC % line in the 24h chart
Type: code
Goal: The 24h chart currently plots battery and grid with Math.abs(), so discharging looks like charging and
import looks like export. Draw them signed around a zero line, and add the battery state-of-charge (%) as its
own line on a right-hand 0–100 % axis, so a NOC operator can read the battery correctly.
Context: frontend/src/components/noc/GenerationOverviewCard.tsx (getY ~line 82, buildPath ~84-100, maxBat/maxGrd ~69,
tooltip/hover readout, legend chips ~210-240, SVG ~340-400). backend/src/solis/solis.service.ts getDailyCurve
(~line 353: each raw stationDay item has `batteryCapacitySoc` in %). Sign rules in .ai/PLAN.md:
battery + = charging, − = discharging; grid + = export, − = import.
Real data today: battery min −3.29 / max +4.34 kW; grid min −0.07 / max 0.
Allowed files: frontend/src/components/noc/GenerationOverviewCard.tsx, frontend/src/types/solis.ts,
backend/src/solis/solis.service.ts (getDailyCurve only), backend/src/solis/solis-mock.service.ts (getDailyCurve only)
Spec:
- Data: add `batterySoc: number | null` to DailyCurvePoint (types/solis.ts). Backend maps
  `item.batteryCapacitySoc` (null if missing). Mock curve produces a plausible SOC curve
  (drops overnight, rises with solar, clamps 0–100).
- Left axis (kW): domain [minVal, maxVal] where minVal = min(0, min of visible battery/grid values) and
  maxVal = max of visible solar/load/battery/grid values (≥1). Nice tick labels incl. negatives, e.g. "-3.3 kW".
  Draw a solid zero baseline (slightly darker than the grid lines) when minVal < 0.
- Remove Math.abs for battery and grid. Area fills go to the zero baseline (not the chart bottom), so the
  discharge area sits below zero. Solar/load areas unchanged (to baseline).
- Small axis-side captions near the zero line: "↑ charge / export" above, "↓ discharge / import" below
  (muted, 10px), only when minVal < 0.
- Battery SOC: purple dashed line (stroke-dasharray 4 3, no fill) on a right axis 0–100 % with ticks
  0/25/50/75/100 %. Its own legend chip "Battery %", on by default. Skip null points (break the line).
- Battery power chip stays "Battery kW" and is now ON by default; grid chip ON by default.
- Hover readout: show signed meaning, e.g. "Battery −0.69 kW (discharging) · SOC 62%",
  "Grid 0.00 kW (no exchange)" / "(importing)" / "(exporting)" using the 0.05 kW idle threshold.
- Keep everything SVG, no new deps, no layout-property animation. Existing look (colours, fonts) unchanged.
Acceptance criteria:

- [ ] SOC line visible with right axis labels 0–100 %.
