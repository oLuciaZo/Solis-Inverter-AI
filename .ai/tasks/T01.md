Spec:
- New pure helpers in solis-units.ts: `toKw(value, unitStr)` (W→/1000, kW, MW→*1000), `toKwh(value, unitStr)`
  (Wh, kWh, MWh), `num(v)` safe Number (NaN→0). Unknown/empty unit = assume already kW/kWh.
- getLiveTelemetry: convert every power/energy via its `*Str` sibling. Fields:
  - gridPower: signed from d.psum (+export/-import). If psum is 0 but psumZheng/psumFu non-zero use Zheng - Fu.
  - batteryPower: signed from d.batteryPower; if unsigned use batteryPowerZheng - batteryPowerFu.
  - batterySoh = invData.batteryHealthSoh (fallback existing); batterySoc = d.batteryPercent ?? invData.batteryCapacitySoc.
  - batteryChargeToday = invData.batteryTodayChargeEnergy ?? d.batteryChargeEnergy; batteryDischargeToday likewise
    (NEVER use d.batteryTodayChargeEnergy — it is wrong/0).
  - gridImportToday = invData.gridPurchasedTodayEnergy ?? d.gridPurchasedDayEnergy; gridExportToday = gridSellTodayEnergy ?? gridSellDayEnergy.
  - gridImportMonth/gridExportMonth from gridPurchasedMonthEnergy / gridSellMonthEnergy.
  - loadToday = d.homeLoadTodayEnergy; batteryMinSoc = invData.socDischargeSet ?? null.
  - acVoltage = invData.uAc1 ?? gridDetailVo.gridVoltageA; acCurrent = invData.iAc1.
  - powerFactor: if invData.isShowPowerFactor===0 or value is 0 → estimate P/sqrt(P²+Q²) from acGridPowerA & acGridReactivePowerA
    (powerFactorEstimated=true) when P>0, else null.
  - gridState / batteryState per PLAN sign rules (idle threshold 0.05 kW; 'full' when idle and SOC ≥ 95).
  - dataSource 'live'. Remove the `loadPower` fallback math only if familyLoadPower exists (keep fallback otherwise).
- getDailyCurve: use per-item unit fields (powerStr, familyLoadPowerStr, batteryPowerStr, psumStr) via toKw;
  delete the "> 15 means W" heuristic. Keep output shape DailyCurvePoint.
- Mock service: return all new fields with realistic values, dataSource 'mock'.
- Update frontend/src/types/solis.ts with the PLAN contract (FlowState, BatteryState types + new fields).
- Unit tests for solis-units.ts (jest already configured in backend).
