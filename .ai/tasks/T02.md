# T02: Animated EnergyFlowDiagram component
Type: code
Goal: A self-contained, presentational SVG energy-flow diagram where particles travel along the power lines,
direction follows the sign of power and speed/density follows kW. Light "Lector" theme (white card content).
Context: .ai/PLAN.md "Design spec" + "Data contract" sign rules. Next.js 16 / React 19 / Tailwind v4 —
read frontend/AGENTS.md first. lucide-react is available.
Allowed files: frontend/src/components/noc/EnergyFlowDiagram.tsx (new), frontend/src/components/noc/energy-flow.css (new)
Spec:
- `'use client'` component, default export none; named export `EnergyFlowDiagram` with props:
  `{ pvKw: number; loadKw: number; gridKw: number /* +export -import */; batteryKw: number /* +charge -discharge */;
     batterySoc: number; batteryState: 'charging'|'discharging'|'idle'|'full'; gridState: 'importing'|'exporting'|'idle' }`
- SVG viewBox 0 0 640 380, width 100%, responsive. Nodes: Solar (top centre-left), Grid (left), Inverter hub (centre),
  Home (right), Battery (bottom). Each node: white circle with coloured ring (solar #ff9a3c, grid #4aa8ee,
  battery #7a4fd0, home #ec4899, hub gradient pink→purple), lucide icon (nested <svg> via x/y), kW value
  (JetBrains Mono / tabular-nums) and a state caption ("Generating", "Importing", "Exporting", "No exchange",
  "Charging", "Discharging", "Full · standby", "Consuming"). Battery node has an SOC arc ring with % text.
- Lines: curved paths Solar→Hub, Grid↔Hub, Battery↔Hub, Hub→Home. Base track light grey (#e9e6f2), active
  overlay coloured. Particles: 3–5 small glowing circles per active line moving with SVG `<animateMotion>`
  (keyPoints="0;1" or "1;0" for reverse) or CSS offset-path; duration = clamp(1.2s, 6s / (0.4 + |kW|), 6s).
  |kW| < 0.05 → line idle: dashed grey, no particles, caption "idle".
- Hub has slow rotating dashed ring + subtle pulse when anything flows. Active nodes get a soft pulse glow.
- `@media (prefers-reduced-motion: reduce)`: no particles/rotation; show static arrowheads (marker-end) in flow direction.
- Small legend under the SVG: "● moving dots = power flow · faster = more kW · grey dashed = no flow".
- Accessible: `role="img"` + `aria-label` summarising the flows (e.g. "Solar 2.3 kW to home; battery idle; grid no exchange").
- Animate only transform/opacity/offset; no layout props. No external deps.
